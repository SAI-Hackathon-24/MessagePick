# 目标
基于目前的设计草稿，整理MessagePick的整体设计需求文档。

# 输入
docs/raw/raw_design.md

# 输出
docs/product/prd.md

# 步骤
1. 阅读并理解raw_design.md
2. 提问确认设计中模糊的地方
3. 将需求以结构化、整齐的形式输出到 docs/product/prd.md
   1. 要求：明确下述内容：
      用户场景:谁、在什么情况下、触发什么动作、想达成什么。写成一句可复述的话,不能是"优化用户体验"这种。
      功能边界:做什么、明确不做什么。不做的部分写清楚,比做什么更有价值。
      交互流程:关键路径逐步走一遍,包括异常分支(空状态、失败、超时、没权限)。
      数据与规则:字段、来源、计算口径、默认值、约束条件。
      验收标准:可判定。能被测试写成用例,而不是"体验流畅"。

# 额外要求
不要擅自做出决定。不要揣测我的意图。有任何不清楚的地方必须通过提问的方式问清楚我。尽量调用copilot内置工具向我提问。

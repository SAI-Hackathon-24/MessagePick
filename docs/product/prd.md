## 1. 用户场景

### US-001 潜水补课
新入群或长期潜水的成员，在大家突然开始刷同一句话、同一张图时，打开梗词云并点开对应梗单元，想快速搞懂「什么意思、怎么来的、现在怎么用」。

### US-002 想接话
想参与讨论的群成员，在不确定某个说法能不能用、会不会过时时，查看该梗的热度状态与用法解读，想放心地用出去。

### US-003 群主复盘
群主或管理员，在做年终总结、新人手册时，用词云与梗生命周期视图复盘群文化，想看清每个梗是谁带火的、火过多久。

### US-004 梗再创作
内容创作者或活跃群友，想把群梗做成表情包或新说法时，在梗单元点「生成」，想直接拿到可复制 / 下载的图与文字变体。

### US-005 防遗漏
使用者在多个群的消息刷屏、通知与活动混杂时，打开消息时间轴与通知总览（按来源、类型、优先级、待办查看），想一眼看清要做什么、什么时间、出自哪个群，不再爬楼。

### US-006 核对原文
使用者对某条 AI 总结存疑、想核对上下文时，点进该条消息，想看到 AI 总结与全部来源群消息，回原文确认。

### US-007 了解某人
使用者想了解某个群友的爱好时，打开其人物兴趣画像、展开标签证据并回到原文，想快速认识对方。

### US-008 找搭子
使用者有一项想找人一起玩的爱好时，按一级维度或具体二级标签搜索，想看谁有同样爱好、找他要等多久（回复时长）、平时活跃不活跃。

### US-009 评估合得来吗
使用者想知道和某个人合不合得来时，查看两人的共同爱好、契合度与逐维度差值，想用数据而不是感觉来判断。

### US-010 组局
使用者想发起活动时，在反向社交结果里选定一个兴趣，想拿到一句可以直接照着用的文字建议（例如「可以约 A、B、C 打羽毛球」）。

### US-011 跨群对齐
使用者发现同一个人在不同群里昵称不同时，在「身份对齐」面板逐条确认或否定候选映射，想让跨群匹配建立在可靠映射上。

### US-012 标签纠错
使用者发现兴趣标签抽取有误或不全时，人工增、删、改标签，想让画像与匹配结果更准。

### US-013 性格标签
使用者想了解某人（或自己）的性格特征时，查看经自己确认后才入库展示的性格标签与分数。

### US-014 更新数据
使用者首次使用、或发现记录过期时，在应用内触发「更新数据」完成采集 / 导入，想让三个模块基于最新记录分析。

### US-015 删除数据
使用者想彻底移除某个群的聊天记录时，执行按群删除或全量清空，想确保原始记录及其派生结果都被删除。

## 3. 交互流程

> 每条路径按「正常路径 → 异常分支」走查；异常分支统一按 REQ-016 兜底，不在每条路径内重复展开。

### 3.1 全局：数据准备与筛选

**路径：首次使用与更新**
1. 打开应用：尚未采集到任何数据时，显示首屏引导（说明 +「更新数据」入口）（REQ-003）。
2. 点击「更新数据」→ 触发采集 / 导入 → 完成后「记录更新至 X」更新为本次完成时间（REQ-002）。
3. 数据就绪后进入主界面：三个模块共用同一筛选条（群多选 · 时间范围 · 关键词 · 当前用户身份）（REQ-004）。
4. 在任一模块调整筛选，其余模块视图同步受同一筛选约束（REQ-004）。

**异常分支**
- 采集 / 导入失败或无授权 → 说明原因 + 手动重试，不静默失败（REQ-016）。
- 筛选后无匹配 → 空态提示 + 一键清除筛选（REQ-016）。

### 3.2 模块一：群聊梗分析

**路径 A：潜水补课**
1. 打开梗词云：字号 = 出现频率、颜色 = 梗类型（带图例）（REQ-020）。
2. 点击任一梗词 → 从该词位置展开梗单元（REQ-022）。
3. 阅读「梗的解读」（什么意思 / 从哪来 / 现在怎么用）（REQ-026）。
4. 查看首现时间（含来源群）与最近调用时间（含距今），需要时点击跳回原始消息（REQ-027）。
5. 查看精华消息：文字与梗图都支持、图片可预览、可展开更多、可看上下文（REQ-032）。

**路径 B：判断能不能接话**
1. 悬停查看出现次数 / 首现时间 / 最近调用 / 类型（REQ-024）。
2. 在单元内看热度状态（活跃 / 衰减中 / 已沉寂，口径见 §4.2）与最近调用时间（REQ-028）。
3. 如说法有变体，点「相关变体」切换查看（REQ-033）。

**路径 C：复盘群文化**
1. 切换词云布局为「按首次出现时间」：词按时间重排、每个词标注首现日期（REQ-023）。
2. 打开梗生命周期视图：条带长度 = 生命周期跨度、标注首现 / 峰值 / 沉寂、按月展示当月领跑梗（REQ-025）。
3. 点击行或单元格回到对应梗单元；需要时切表格视图复制数据（REQ-025）。

**路径 D：再生成与创造新梗**
1. 在梗单元左下角点「生成」（REQ-034）。
2. 生成表情包：选素材档位（三档单选其一）与模板 → 编辑文案 → 生成 4 张 → 复制 / 下载（REQ-036）。
3. 生成文字变体：默认 5 条 → 一键复制（REQ-037）。
4. 创造新梗：生成候选梗单元（含义推测 / 出处消息 / 使用示例）→ 使用者确认 → 入库并进入词云等视图（REQ-038）。

**纠正路径（贯穿）**
- 对梗改判「这不是梗」「不感兴趣」「合并到其他梗」「梗王标注有误」→ 立即影响后续结果（REQ-035）。

**异常分支**
- 生成失败 / 超时 → 提示 + 重试；已加载的词云与单元不受影响（REQ-016）。
- 无数据 / 筛选无结果 → 空态（REQ-016）。

### 3.3 模块二：群聊信息提取

**正常路径**
1. 打开消息时间轴：全部提取消息按时间排序；用群多选可只看选定群（REQ-047）。
2. 切到通知总览：按来源 / 类型 / 优先级 / 待办查看；优先级与主题可修改（REQ-045、REQ-044）。
3. 待办处理：标记「完成」或「忽略」；到期前应用内出现提醒（REQ-046）。
4. 点进一条消息：heading = AI 一句话总结 + 来源群 + 时间；正文 = AI 总结 + 所有群消息来源（REQ-048）。

**异常分支**
- 分析 / 抽取失败或超时 → 提示 + 重试，已提取内容仍可浏览（REQ-016）。
- 无数据 / 无结果 → 空态（REQ-016）。

### 3.4 模块三：正向 / 反向社交

**路径 A：正向（人 → 兴趣）**
1. 打开某成员的人物兴趣画像（REQ-061）。
2. 点任一兴趣标签的证据 →「打开更多」查看原文（REQ-053）。
3. 查看爱好雷达图：五轴 = 一级五类；点击轴展开二级词条（REQ-071）。

**路径 B：反向（兴趣 → 人，找搭子）**
1. 选择检索入口：按一级维度（如「运动维度分高的人」）或按二级标签（如「乒乓球」）（REQ-064）。
2. 结果中查看每人的回复时长与活跃度（REQ-065）。
3. 选定一个兴趣 → 生成组局建议：仅文字（如「可以约 A、B、C 打羽毛球」），不生成待办、不生成可直接发送的文案（REQ-063）。

**路径 C：评估与人相处**
1. 选两人 → 查看共同爱好 + 契合度 + 逐维度差值（雷达叠加对比）（REQ-062、REQ-059）。
2. 查看「我的社交契合度」：我 vs 每个群友（列表）+ 整体融入度（单一分数）（REQ-079）。

**路径 D：身份对齐（跨群匹配的前置）**
1. 打开模块三「身份对齐」面板：逐条查看候选映射（如「A 群的张三 = B 群的小张」；候选结合通讯录 / 好友列表）（REQ-082）。
2. 确认 → 映射生效；否定 / 未确认 → 不生效，相关人按各自独立个体处理（REQ-082）。

**路径 E：人工介入标签**
1. 兴趣标签：增 / 删 / 改（含同义合并结果的修正）（REQ-056）。
2. 性格标签：查看 LLM 候选 → 由使用者确认 → 入库展示；未确认的候选不出现（REQ-075）。

**异常分支**
- LLM 抽取 / 分析失败或超时 → 提示 + 重试；已有画像与列表可继续浏览（REQ-016）。
- 无授权（通讯录 / 采集不可用）→ 说明原因 + 手动重试（REQ-016）。
- 无数据 / 搜索无结果 → 空态（REQ-016）。

### 3.5 降级路径（模块三）

- 发言太少、无法推断兴趣的成员：标「未知」、不推测，但仍列出；在人-人图谱中零连线（REQ-081）。

### 5.5 端到端演示路径（模块一，源自 raw_design §3.8）

1. 打开词云 → 字号差异明显、图例可辨类型、点击任意词展开单元（REQ-020、REQ-022）。
2. 点击「下次一定」→ 单元显示解读、首现时间、最近调用、按月分布、名场面（含梗图）、梗王（REQ-026、REQ-027、REQ-029、REQ-032、REQ-031）。
3. 切「按首次出现时间」→ 词云重排为时间序、每词带首现日期（REQ-023）。
4. 切到梗生命周期视图 → 条带可辨、已沉寂的梗一眼看得出（REQ-025、REQ-020）。
5. 点单元左下角「生成」→ 得到 4 张表情包 + 5 条文字变体，可复制 / 下载（REQ-034、REQ-036、REQ-037）。
6. 点「创造新梗」→ 得到 1–2 个候选梗单元，确认后才进入词云（REQ-038）。
